# Google Sheets 快照分頁

先載入 `google-workspace` skill 並讀它的 `references/sheets.md`（寫入規則、欄位遮罩、驗證）。

- 試算表「交易紀錄」：ID 寫在專案的 `CLAUDE.md`；沒寫時用 Drive 搜 `title contains '交易紀錄'`，找到多份就問使用者。
- 新分頁名稱「持倉快照 <YYYY-MM-DD>」，放在前一份快照分頁旁邊。既有分頁只讀不改（「月統計」例外，見文末）。
- 快照的價格一律填數字，不用 GOOGLEFINANCE，分頁才不會隨時間變動。前導零代號加 `'`（`'00878`）。

## 建立方式

**優先複製上一份快照分頁**：`duplicateSheet`（`newSheetName`、`insertSheetIndex`），再用 `insertDimension`／`deleteDimension` 在各資料區塊「內部」增減列，讓列數符合這次的持股數。插在區塊內部時，SUM、SUMIFS、圖表、交錯底色與條件格式的範圍會自動跟著調整；插在合計列正下方或標題列上方則不會。改完結構先讀回版面，再寫數字。

沒有可複製的分頁時，照下面的版面從頭建。

## 版面

| 區塊 | 內容 |
| --- | --- |
| 標題 | A1 標題；A2 資料來源一行；A3「USD/TWD」、B3 匯率（藍字，註記來源與日期） |
| 證券持股表 | 欄位：帳戶、代號、名稱、市場、槓桿倍數、幣別、股數、成交均價、投資成本、現價、市值(原幣)、市值(台幣)、未實現損益(原幣)、報酬率、占比、槓桿調整後曝險(台幣)、備註；最後一列「合計」 |
| 市場彙總 | 市場、市值(台幣)、占比、槓桿調整後曝險(台幣)、曝險占總市值；最後一列「合計」。右邊放柱狀圖 |
| 期貨表 | 類別、券商代碼、合約、到期日、方向、口數、每點價值、成交均價、最新價、未實現損益、名目本金、備註；最後一列「合計」 |
| 帳務 | 標籤在 A、金額在 C（期貨帳務欄位） |
| 兩帳戶合計 | 證券總市值、期貨權益數、資產合計、股票台股曝險、期貨名目本金、台股總曝險、總曝險／資產合計；D 欄放灰色斜體說明 |

公式（列號依實際位置）：

- 證券：市值(原幣) `=G*J`；市值(台幣) `=IF(F="USD",K*$B$3,K)`；報酬率 `=IF(I=0,0,M/-I)`；占比 `=IF($L$合計=0,0,L/$L$合計)`；曝險 `=L*E`。
- 市場彙總：`=SUMIFS(市值欄,市場欄,A列)`，占比與曝險同理，合計用 SUM。
- 期貨：未實現損益 `=IF(E="買進",1,-1)*(I-H)*F*G`；名目本金只給期貨列 `=I*F*G`。
- 兩帳戶合計全部引用上面的格子（證券合計、權益數、市場彙總的台股曝險、`SUMIFS(名目本金,類別,"期貨")`）。

成本照 CTS 記負數（與「股票成本統計&紀錄」一致）。投資成本與未實現損益是照抄的資料，市值、報酬率、占比、曝險、合計都是公式。

## 樣式

- 全分頁 Arial 10、隱藏格線、不凍結列或欄（兩張表共用一頁，凍結的標題會蓋錯表）。
- 標題列底色 #6D9EEB、粗體置中；資料列交錯底色白／#F5F8FD；合計列底色 #E8EEF9、粗體，上緣 #6D9EEB 粗線；外框 #BFBFBF、內部橫線 #E3E3E3、無直線。
- 損益與報酬率：正數紅 #D93025、負數綠 #188038（台股慣例）。槓桿倍數 >1：橘字 #B45F06、底 #FCE5CD。占比：白到 #9EC5F4 漸層。
- 柱狀圖：市場占比（藍 #2A78D6）與曝險占總市值（橘 #EB6834），圖例在上，數值標籤深灰 #444444，寬 800、高 340，錨定在市場彙總右側。
- 窄欄裡的區塊標題（例如 A 欄的「帳務（日期 結算）」）靠左對齊，讓文字溢出到右邊空格。
- 來源註記放在每張匯入表的左上標題格（`updateCells` 的 `note`）。

## 驗證

`get_values` 讀回整個分頁：沒有 `#REF!`、`#N/A` 等錯誤；證券合計、期貨損益合計、資產合計與筆記一致（公式捨入差 1–2 元可接受，要說明）。另讀「股票成本統計&紀錄」A:I，列出股數與 CTS 不同的標的。

## 月統計（使用者要求才做）

「月統計」每月一列：A 欄年月是文字（寫 `'2026/11`），F 欄統一期貨「現有權益數」填帳務的權益數，加註記說明日期是否為月底。G 欄損益公式 `=F本列-F上列-J本列` 需要 J 欄當月出入金；出入金不確定時 G、J 都不填，在回報中說明。
