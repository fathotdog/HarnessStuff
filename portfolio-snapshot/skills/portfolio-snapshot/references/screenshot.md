# 把快照分頁截成一張圖

整個分頁一次放進畫面後，分成 2×2 四塊高解析度擷取，再拼成一張。

1. 在 Claude 分頁群組開新分頁，網址 `.../edit#gid=<分頁 sheetId>`。
2. 工具列縮放選單選 50%；`ctrl+shift+f` 收起選單列，再從「查看」→「全螢幕」收起工具列與公式列。截一張全畫面，確認第 1 列到最後一列、A 欄到最後一欄都看得到。
3. 用名稱方塊選內容以外的格子（例：最後一列下方的 A88），避免選取框入鏡；`hover` 把滑鼠移到右側空白處。
4. 從全畫面截圖量出內容邊界：A 欄左緣到最後一欄右緣、第 1 列上緣到最後一列下緣（不含列號與欄標題）。切成四塊大小相同的區域，各自 `zoom` 並 `save_to_disk: true`。不要加 `scale`：它會連存檔一起縮小。
5. 在 vault 根目錄拼接（`<skill>` 是本 skill 的目錄，載入時顯示為 Base directory）：
   ```
   uv run --no-project --with pillow python -I <skill>/scripts/stitch.py --tiles TL.png TR.png BL.png BR.png --out portfolio/<YYYY-MM-DD>_持倉快照.png
   ```
   腳本會裁掉頂端殘留的欄標題線，並以標題列藍色的右緣裁掉右側。畫面上若有協作者游標框（空白格上的彩色方框，常見於使用者另開的視窗），在拼好的圖上量出座標，加 `--blank x0,y0,x1,y1` 塗白；只塗空白格，不碰任何數字。
6. 用 Read 打開 PNG 檢查：所有區塊完整、接縫對齊、字可讀。
7. 還原：`Escape` 退出全螢幕，縮放改回 100%，關閉分頁。
